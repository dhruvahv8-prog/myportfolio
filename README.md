# Dhruva H V — Portfolio

This is a static HTML/CSS/JavaScript website prepared for Vercel and GitHub Pages.

## Important folder structure

- `index.html` must remain at the repository root.
- `certificates/` must remain beside `index.html` because the certificate links use relative paths.

## Deploy on Vercel

Import the GitHub repository into Vercel and use:
- Framework Preset: Other
- Root Directory: `./`
- Build Command: leave empty
- Output Directory: `.`
- Install Command: leave empty

Then deploy. Vercel will serve `index.html` at the site root.
